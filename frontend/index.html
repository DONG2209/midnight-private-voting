      Privacy model

      An observer CAN learn

      • The ballot's title and open/closed status
      • The running YES / NO / ABSTAIN tallies, updated after every vote
      • How many distinct ballots have been cast in total
      • The raw set of nullifiers used so far (opaque 32-byte values)
      • That some vote just changed the tally in a given direction

      An observer CANNOT learn

      • Which wallet or person cast any particular ballot
      • Which of the tally changes belongs to which nullifier
      • Whether the same person voted in two different ballots — nullifiers are domain-separated per ballot
      • The admin's secret key — only a one-way hash of it is ever public
